Delivery pipeline

  1. Git / GitHub: feature branches, pull requests into develop, releases tagged on main.
  2. Maven: mvn clean test and mvn package build tracker.war.
  3. Jenkins: build, unit tests, Selenium tests, Docker image, deploy, health check.
  4. Selenium: browser journeys run against an isolated instance on port 8083.
  5. Docker: versioned image, container on port 8082.
  6. Ansible: idempotent playbook provisions the node and deploys a chosen version.
